MVP / local evaluation

A patch is a proposal.
Make its evidence reviewable.

Ten synthetic cases. Declared criteria. Inspectable before-and-after observations. No API key, backend, or model call.

This is a workflow demonstration. The fixture outcomes do not measure the success rate of a coding agent. Open a case to inspect its checks, limitations, logs, and replay instructions.
